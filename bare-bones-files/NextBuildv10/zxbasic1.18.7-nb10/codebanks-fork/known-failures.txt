# Functional tests that fail on this fork, and why.
#
# Every one of these is caused by the fork, deliberately. The golden .asm files
# embed the runtime library source and the exact code we generate, so any
# intended change to either shows up here as a "failure".
#
# run-tests.sh diffs the live failures against this list, so a NEW failure is
# reported even though the count does not move. Blank lines and #comments are
# ignored. Refresh by deleting this file and re-running --func, having read
# every difference first.
#
#   19x arch/zxnext   our ZX Next runtime keeps its own implementations where
#                     upstream stubs out to zx48k -- e.g. array/array.asm uses a
#                     local buffer for LBOUND_PTR instead of MEMBOT (23698), and
#                     the goldens contain the library text verbatim.
#
#    5x arch/zx48k    back-port f181dc88 "detect static expressions better".
#     (dim_at0,       `DIM x AS Uinteger = @label` inside a SUB now compiles to a
#      dimconst2*)    direct store rather than an LDIR from a 2-byte blob. Ours
#                     is the smaller code; upstream v1.19.0's golden still shows
#                     the LDIR, so we diverge from them here too.
#
#    2x cmdline       back-port f7849bd6 "fixes wrong sigil allowed" emits an
#                     extra diagnostic the expected output predates.
