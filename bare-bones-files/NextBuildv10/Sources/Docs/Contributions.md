## NextBuild Studio Under The Hood 

NextBuild makes use of : 

  - PlayPT3: 
    -  multi-pt3 player by Volutar 2021-12-21
    -  Ayumi AY/YM synth engine by Peter Sovetov
    -  https://github.com/Volutar/pt3player

  - itch-dl 
    - Dragoon Aethis
    - https://pypi.org/project/itch-dl/

  - SpecNext Wiki 
    - Articles directly taken, or inspired and used as a reference from the official Wiki 
    - https://specnext.wiki

  - Help files from ZX Basic Compiler 
    - Articles and help by Boriel 
    - https://zxbasic.readthedocs.io/en/docs/

  - Bearded Themes 
    - Colour themes by BeardedBear
    - https://github.com/BeardedBear/bearded-theme

  - JS AY routines 
    - AY generation and playback by Remy Sharp 
    - https://github.com/remy/zx-tools

  - Inno Setup 
    - Build tools for deployment 
    - https://jrsoftware.org/isinfo.php

  - Maziac's NEX file viewer  
    - Allows viewing of NEX data structure 
    - https://github.com/maziac/nex-fileviewer

  - Maziac's Z80 Instruction Set
    - Z80 Syntax Helper 
    - https://github.com/maziac/z80-instruction-set

  - Maziac's HEX Hover Helper 
    - HEX value hover details 
    - https://github.com/maziac/hex-hover-converter
  
  - Vortex Tracker play routines 
    - Playback of the pt3 and turbosound (dual pt3) files 
    - (c)2004,2007 S.V.Bulba <vorobey@mail.khstu.ru>

  - AYFX engine 
    - AY sound effect engine by Shiru 
    - https://shiru.untergrund.net/

  - gfx2next 
    - Graphics ripping / prepping tool 
    - [Ben Baker ](https://www.baker76.com/gfx2next/)

  - HDFMonkey 
    - HDF Manipulation tool 
    - (c) Matt Wescott https://github.com/gasman/hdfmonkey

  - VSCode Action Buttons 
    - Configurable status bar buttons 
    - https://github.com/seunlanlege/vscode-action-Buttons

  - VSCode Icons 
    - Visual custom icon set for VSCode 
    - https://github.com/vscode-icons/vscode-icons

### 🧠 **ZX Basic Compiler** by José Rodríguez (boriel)

**Without this, NextBuild is just a fancy text editor**

José's ZX Basic compiler is what actually does all the hard work:
- 🚀 Turns your BASIC into lightning-fast Z80 code
- 📚 Massive library of functions ready to use
- 🎯 Works on 48K, 128K, and Next
- 🔧 Mix BASIC and assembly when you need to get dirty
- 📦 So flexible, it makes bananas look straight
